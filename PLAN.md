I am building a climbing app for climbing gyms, where users can upload beta for routes at their climbing gym so other users can view the beta and help them send their projects.

users should be able to upload videos, see other peoples videos, track there sends, favorite gyms and favorite climbs, comment on climbs and view other users profiles. user profiles should have an avatar, users height, max grade, username

there should be a gyms page which shows all the available gyms where users can search for their gym. each gym should have its own page, where you can find its location (city, adresss etc.) the gym page should list all the routes in the gym sortable by grade, color, type, which wall they are on.

Each route should have its own page, where you can see the routes information (color, grade, type, name) as well as all the beta videos associated with that route and a way to upload videos for that route.
